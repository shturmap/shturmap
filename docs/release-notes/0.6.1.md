**Shturmap 0.6.1 "Okami"**

Shturmap is a second-monitor map for Escape from Tarkov: your active quests' objectives, the extracts and your
position on the map of the raid you're in, in one window beside the game.

**New since 0.6.0.**

- **Your extracts, called out more slowly.** Each icon of the roll call now flies 1.5 s to its place and lifts off 0.4 s
  after the one before. 0.6.0 flew them in 0.9 s, 0.16 s apart, so eight icons were in the air within a second and the
  farthest crossed a third of the map in under one: too fast to follow. With six extracts the last now lands at 5.1 s and
  the title stays until 6.6 s.
- **Above or below you, bolder.** The small badge at a marker's upper right that says a place lies on another floor
  holds a bold caret in a 14 px disc, where a filled triangle of 6 by 5 px in an 11 px disc read as a dot on a small
  second screen (a beta tester's report). Two or more floors away, a larger plate holds the caret and an 11 px digit.
  Names keep clear of the badge, and the legend shows the new shape.

**This is an early release.** Expect rough edges. The story chapters (Falling Skies, Batya, …) aren't shown yet:
tarkov.dev doesn't publish them. If something is wrong or missing, tell us from the app: the **feedback** button at
the top right. No account needed. With a GitHub account you can also open an issue in this repository; issues are
public, so leave the game's logs, screenshots and ids out of them.

**Built where you can check it.** Every release is built and published by the repository's own GitHub Actions
workflow from the tagged commit, with a signed build-provenance attestation. To check that a download
is that build: `gh attestation verify Shturmap-Setup.exe -R shturmap/shturmap`, or compare its SHA-256
(`Get-FileHash Shturmap-Setup.exe`) with the `.sha256` file beside it. The README says what the tests check on every
push.

**What it reads, and what it never does.** Shturmap reads the game's own log files (quests started, completed and
failed, the items a quest hands you; the map you load into), the file names of your screenshots, which the game fills
with your position (Battlestate's support article on [reporting a bug](https://www.escapefromtarkov.com/support/knowledge/437)
describes these coordinates; a source, not an endorsement), the extract list in a raid screenshot's top right
corner, and the item cells in a screenshot you take in the menus, for the items your quests need (settings turn each
off). It never reads the game's memory, never sends input to the game, never captures the screen and never changes
game files; its own code never opens the game's process (the installer it comes with looks through running programs
to close Shturmap when it installs or updates: the README says exactly what that means). Outside its own folders it
deletes one thing, and only with **Delete screenshots after reading** ticked: a screenshot you just took, once read.
It shows your position to you only: it never shares it with anyone and never takes a screenshot for you. Data and
map artwork come from tarkov.dev.

**Use at your own risk.** Shturmap is an unofficial fan project, not made or endorsed by Battlestate Games.
Battlestate's License Agreement (section 4.3.4) lets it decide which outside software it permits, so there is no
guarantee against sanctions. Some players see a map with your own position as an unfair advantage in PvP; Shturmap
is at its most useful for learning maps and in PvE.

**Install.** Download `Shturmap-Setup.exe` below and run it (64-bit Windows 10 2004 or later, or Windows 11). It
installs for your Windows user only, with no admin rights, and adds a Start-menu and a desktop shortcut. The installer
isn't signed, so Windows warns about it: click **More info → Run anyway**. Uninstall it under Windows Settings → Apps,
or settings (the gear) → **Uninstall Shturmap…**; your data in `%LOCALAPPDATA%\Shturmap` stays unless you tick **Also
delete my Shturmap data** there.

**Updates.** Shturmap keeps itself up to date: it asks GitHub for a newer version at start and every 6 hours,
downloads it in the background and applies it the next time you start it, never during a raid. Settings (the gear) →
**Updates** switches between Automatic, Tell me only and Off.

**What is sent.** Nothing about you or your game, unless you send a report or allow crash reports. Its other
traffic downloads public data and map artwork, and asks GitHub for a newer version (settings → **Updates** turns that
off). **Privacy** in settings says exactly what a report holds and who receives it.
